# Discrete Math

## Backtracking

- The essence of `backtracking` is wrapped only in 3 words: try -> move forward -> undo (to try another). 
- It's approriate for the problem where there are multiple choices at each position. 
- The array `visited` (or marking array) is essentially used when there is resource competition – that is, an element/state is allowed only once (no repetition) in the same configuration .
